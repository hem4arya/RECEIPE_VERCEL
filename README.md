## 🚀 Quick Start (The "One-Click" Way)

### For Windows Users 🪟

1.  Double-click **`WINDOWS_START.bat`**.
2.  Follow the on-screen instructions.
3.  **Enjoy!** The app will open in your browser automatically.

### For Linux/Mac Users 🍎🐧

1.  Open your terminal.
2.  Run: `./LINUX_START.sh`
3.  **Done!**
